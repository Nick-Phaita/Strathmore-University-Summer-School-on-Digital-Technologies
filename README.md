# Strathmore-University-Summer-School-on-Digital-Technologies 

# Configuration and System Management with Ansible: Linux systems (Web, Cloud Ochestration Systems)


# What you will learn 

- Environment Setup and Installation
- Introduction to Ansible Core Concepts 
- First Ansible Playbook 
- Inventory, Variables, Roles and Tasks 
- Simple Service Automation with Ansible : Web Service (Apache and Nginx) 
- Advanced Service Automation with Ansible : Docker, MicroK8s and Helm setup Scenarios



# Good to know Pre-requisites 

- Basic interaction with the Bash command-line shell (pipes and redirection)
- Working with SSH
- Installing packages
- Use the sudo command
- Check and set file permissions
- Start and stop services
- Set environment variables
- Write scripts (any language) is good enough
